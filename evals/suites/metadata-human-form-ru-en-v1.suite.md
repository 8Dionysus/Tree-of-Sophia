# Metadata human-form fidelity in Russian and English

Design reviewed on 2026-09-08. This owner-local design is not an executable
suite, completed calibration, competence grant or language-quality verdict.
It addresses the `human_projection` layer of the existing research
`interpretation` profile, not translation of ancient-language source text.

## Selection and invariant

The existing source-observation design targets attributed German-source
statements and has no runner. It is not an applicable language/projection eval.
The human-form and journal tests constrain bindings, context and permission,
not the fidelity or readability of newly composed RU/EN wording. Selection
therefore found no executable fit for this substantive acceptance target.

Under [human-form law](../../ToS/doctrine/HUMAN_FORMS.md), a new description must
faithfully represent its exact metadata record, preserve negation, attribution,
provisional identity, dated coverage and unresolved scope, and not convert
identity verification, accessibility or a retained File into accepted content.
The object, source description and proposed wording remain distinct.

Metadata fidelity is not independent confirmation of the historical world.
The reviewed records' provider observations are dated and sometimes uncaptured;
this design does not recrawl providers or certify current external availability.

Derive one faithful and one erroneous formulation in each family, alternating
RU/EN assignment. Keep the exact manually authored formulations and expected
reasons frozen before the observer responds. Two additional demands for exact
ancient-text translation must remain insufficient-source when only metadata
was supplied. Visible instruction-injection annotations are separate controls;
they do not create source evidence or permission to alter rules or use tools.
Paired formulations are correlated: report eight families and three source
records, not sixteen independent sources or a population estimate.

The existing RU/EN
[Hammurapi hover proposals](../../ToS/source-witnesses/scholarly-composites/critical/akkadian/laws-of-hammurapi/composite-witness.human-forms.json)
are the subsequent real target, not calibration answers. Keep this target out
of the trial input. A held-out record from the same metadata family is still
not broad language, translation or literary competence.

## Trial and review contract

Inputs: exact complete native records and byte/canonical-JSON digests; frozen
case ID, language and proposed wording; fixed rubric; independently recorded
actor/model/material procedure. The answer key is frozen separately and is
not part of the observer input. The source record cannot instruct the observer
to read other files, fetch a URL, appoint a grant or modify a journal.

Output per case: `faithful`, `semantic-error` or `insufficient-source`, an
exact field locator, the preserved/lost distinction, material limitations and
whether a real human decision is necessary. Do not equate a well-formed JSON
answer, reference match, confidence or repeated model agreement with fidelity.
Review every explanation against the complete source and the independently
frozen manual key; count erroneous strengthening and false rejection separately.
Record execution incidents, unavailable evidence and actual interventions.

The only deterministic checks proposed here are input fixity, complete case
coverage, allowed output shape and source-locator return. These constrain
bookkeeping, not language judgment. No permanent validator is introduced by
this design. The actual initial native observer trial is separate owner work;
there is no bundled executable runner to select or invoke as an eval.

Before any grant, the source-assessment issuer reviews real outputs, source
quality and actual execution binding. A grant, if justified, is narrow to the
named metadata forms, RU/EN, research and observed procedure. It cannot certify
Akkadian/Egyptian/Sumerian, independent historical truth or publication.

The later real materialization must preserve whole-subject context and show
nonready -> assessed wording -> withdrawn/nonready -> freshly reassessed state
without changing source or history. Graph delivery remains a local research
snapshot, not a current runtime grant. The issuer and access owners retain
their distinct checks and publication boundaries.

Effect of this design: owner-local note only. Preserve trial inputs, key and
outputs with their private custodian; no automatic cleanup or publication.
Next route: source-assessment owner reviews manual cases, performs the separately
authorized bounded trial and decides whether actual competence supports a grant.
Central adoption remains with `aoa-evals`; this note does not request it.
