# AGENTS.md

This card applies to repository documentation under `docs/`.

## Role

This directory owns durable rationale in `docs/decisions/`, the release
procedure in `docs/RELEASING.md`, validation/testing navigation and the historical
root locator in `docs/AGENTS_ROOT_REFERENCE.md`.

## Boundary Routes

Edit the exact owner guide. Current knowledge law stays in `ToS/doctrine/`,
research and review evidence in their `ToS/` homes, and operation contracts in
`mechanics/`. Decision records explain rationale; they do not override current
source. Rebuild generated indexes from their authored inputs.

Keep current instructions separate from dated evidence. Retire duplicated
historical prose with an exact, recoverable source locator; preserve unique
rationale, provenance, rights and review outcomes.

## Validation

Use [docs/VALIDATION.md](VALIDATION.md) for route/documentation checks and
native decision-index regeneration. Add the affected source-owner route when
a guide changes an actual contract.
