# ToS observation manifests

Tree-of-Sophia owns the machine-readable recurrence posture for Agon threshold
intake. The stack or OS owner runs any live hooks.

- [Component](recurrence/component.tos.agon-threshold-intake-surfaces.json)
  names the observed registry, configuration and schemas.
- [Hook bindings](recurrence/hooks/component.tos.agon-threshold-intake-surfaces.hooks.json)
  describe observe-only drift and authority-leak detection.

Use the `mechanics_local` lane in [mechanics validation](../mechanics/VALIDATION.md)
for the named mechanic. There is no separate export or import command.
