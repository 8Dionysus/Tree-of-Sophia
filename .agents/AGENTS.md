# AGENTS.md

This card applies to `.agents/`.

## Role

This directory maps optional profile bindings and ToS-local owner ports through
`.agents/agent-surface.manifest.json`; `.agents/README.md` is the human guide.

## Boundary Routes

Keep profile declaration, installation, model visibility and invocation as
separate states. Shared packages retain their homes and profile-owned discovery;
a ToS-local procedure needs explicit admission before adding a skill projection.
The current contributor route keeps shared-skill projection outside this
repository.

## Validation

Review the manifest, owner references and public-safety boundaries by hand.
