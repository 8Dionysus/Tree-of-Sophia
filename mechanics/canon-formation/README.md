# Canon Formation

<a id="active-route"></a>

Canon Formation routes reviewed candidates toward [canonical ToS sources](../../ToS/canon/AGENTS.md).

## Operations

### Promotion gate

Collect the candidate object, source anchor, evidence status and review state.
Use the [review checklist](../audit/parts/review-ledger-route/docs/REVIEW_CHECKLIST.md)
and the relevant canon and relation validators, then route accepted material to
its canon owner or return it for review. Run:

```sh
tos-ops-mechanics-plan --repo-root ROOT --tree-node-validate
```

Select `mechanics_local` or `canon_contracts` in
[mechanics validation](../VALIDATION.md) for the affected surface.

graph-workbench, candidate-intake or canon owner routes.
