# No Direct Polis Governance Write

Status: candidate
Repo landing: `Tree-of-Sophia`
Layer: Experience governance boundary

## Purpose

Prohibits direct runtime governance writes into ToS.

The shared governance review law, authority checks, and consent requirements are
maintained in [TOS_GOVERNANCE_REVIEW_NOTE](TOS_GOVERNANCE_REVIEW_NOTE.md).

## Local guard

Runtime governance packets must not write into ToS directly or mutate canon
without the owner review and admission routes.
