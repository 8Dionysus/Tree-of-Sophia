# No Direct Experience Install Write

Version: 1.0.0

## Purpose

Reinforces the boundary that installation and release artifacts are not direct ToS authored nodes.

The v1.0 intake scope, owner route, review flow, and exit criteria are maintained
in [INSTALLATION_DOSSIER_BOUNDARY](INSTALLATION_DOSSIER_BOUNDARY.md). Cross-layer
release authority remains with [Agents-of-Abyss](https://github.com/8Dionysus/Agents-of-Abyss/blob/main/mechanics/experience/parts/release-deployment/README.md).

## Local guard

Installation and release artifacts are dossiers for review; they cannot be
written directly as ToS nodes, installed as canon, or used to bypass reviewed
lineage.
