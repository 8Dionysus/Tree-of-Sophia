# Relation Weaving

<a id="active-route"></a>

Relation Weaving routes proposed graph fragments through review toward
canonical relation packs.

## Operations

### Graph promotion

Collect proposed nodes, relations, branch fragments and the promotion ledger.
Review them with the [graph workbench](../../ToS/philosophy/graph-workbench/AGENTS.md)
and the [relation-pack contract](../../ToS/doctrine/RELATION_PACK_CONTRACT.md);
route accepted relations to `ToS/canon/relations/` and return unresolved work
to review. Validate the route with:

```sh
tos-ops-mechanics-plan --repo-root ROOT --relation-pack-validate
```
