This card applies to `mechanics/release-support/`.

## Role

Release Support keeps ToS release-facing checks source-home aware.

## Boundary Routes

through the landing and release owners. This package owns checked state
transition support.

## Validation

[`mechanics/VALIDATION.md`](../VALIDATION.md) after the release-facing surface
is known. The release owner retains the procedure.
