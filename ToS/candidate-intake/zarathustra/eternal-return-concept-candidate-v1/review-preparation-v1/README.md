# Eternal return review preparation v1

This additive pass prepares the existing eternal-return concept candidate for a
bounded source-visible review. It does not record a review outcome.

The pass performs three complete technical jobs:

- returns and classifies all five retained DE/RU gap locations without changing
  witness text or paragraph alignment;
- creates a speaker-attribution candidate for every selected core/supporting
  unit in `p3.r2`, `p3.r13`, `p3.r16`, and `p4.r19`;
- places each of the five interpretation axes in a matrix of positive evidence,
  counterpressure, speaker dependency, and review questions, alongside the
  poetic-symbolic competitor and the blocked cross-work `amor_fati` slot.

Tracked files withhold exact witness strings. The mode-`0600` private analysis
contains source-returned German and Russian text, reversible normalization
proposals, and concise source excerpts for review. A proposed normalization is
never substituted for observed text.

`review-worklist.v1.json` compresses the future human decision surface to the
five gap packets, speaker-boundary exceptions, and interpretation axes. The 159
ordinary speaker candidates remain fully inspectable but do not become 159
manual tasks.

All records remain `unreviewed` or `prepared_for_review`. This route issues no
review IDs, writes nothing to `ToS/review-ledger/`, materializes no claims or
relations, and has no graph or canon effect.

The implementation and focused validation are owned by
`scripts/build_zarathustra_eternal_return_review_preparation_v1.py` and
`tests/test_zarathustra_eternal_return_review_preparation_v1.py`; execute them
through the [ToS validation routes](../../../../VALIDATION.md).
