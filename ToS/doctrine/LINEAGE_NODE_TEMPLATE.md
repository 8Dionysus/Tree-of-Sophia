# Lineage Node Template

A lineage node gives a source-linked path of development a stable authored identity.

## Core fields

The scaffold uses the shared [node contract](NODE_CONTRACT.md):

- `node_id`
- `node_type = lineage`
- `source_anchor`
- `key_terms`
- `distilled_thesis`
- `relations`
- `interpretation_layers`

## Use the scaffold when

- The path itself needs an authored handle.
- Naming the movement clarifies a branch and the relations among its members.
- The source basis and review scope are explicit.

## Pilot scope

The current scaffold supports the reviewed pilot: one family, a small cluster
and an explicit path through it. Further families and branch growth follow
their own source proposals and review.
