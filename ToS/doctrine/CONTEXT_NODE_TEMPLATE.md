# Context Node Template

A context node describes the temporal, geographic, linguistic, civilizational or institutional setting needed to understand source-linked thought.

## Core fields

The scaffold uses the shared [node contract](NODE_CONTRACT.md):

- `node_id`
- `node_type = context`
- `source_anchor`
- `key_terms`
- `distilled_thesis`
- `relations`
- `interpretation_layers`

## Use the scaffold when

- A source or concept needs explicit contextual framing.
- The context deserves a stable authored handle.
- The account identifies its evidence and explains how the setting matters to the subject.

## Growth route

The template supplies a reviewable form for contextual knowledge. A concrete
context node enters through its source proposal and branch review. New corpus
slices and branch families follow their own growth decisions.
