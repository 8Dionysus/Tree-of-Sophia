# Synthetic repository Artifact templates

These declared input prototypes belong to the explicit synthetic repository
resource route. They are separate from historical Artifact v2 templates and
carry no native creation receipt. The three small source resources are actual
prototype referents; their hashes in the corresponding JSON are exact.

The producer must bind selected template paths and hashes in its profile,
then instantiate each new Artifact ID, resource URI, actual resource size and
digest, custody, rights scope, discovery target and provenance outputs
together. Prototype event IDs and support references are design placeholders,
not observed events or admitted witnesses. The discovery input is planned;
it supplies no query, acquisition or timing result. Generated resource,
rights, discovery and event members are counted separately from the five
meaningful record classes and verified at complete physical EOF.

The source policy, research and philosophical boundary assessment lives in
`ToS/review-ledger/2026-10-05-synthetic-repository-artifact-boundary.md`.
Schema validation of these prototypes does not establish semantic admission,
rights, canon, publication, benchmark success or native v2 mutation cost.
