# Native derived TextLayer comparison review

Review date: 2026-09-09. Local implementation baseline:
`4efd30acdabb684eb14ad1a09356c8df0468afb8`.

## Scope and source review

The existing private v5 assessment selection now resolves the native correction,
Unicode normalization and supplied transcription/OCR recording profiles through
a separate, additive comparison contract. The old structural-extraction
comparison retains its identity and positive-use equality requirement. Neither
profile supplies the substantive judgment made by an authorized reviewer.

The source and authority review found these boundaries preserved:

- Yes: exact source File, XHTML member and supported structural selector return
  the original UTF-8 member and selected text. All oldest-to-newest native layer
  records, representations, policies and configuration digests remain visible.
  Source and output may intentionally differ; a reproducible delta is not
  textual fidelity or a positive quality decision.
- Yes: source metadata and each predecessor's rights are resolved before any
  selected representation or original content. Current independently selected
  grants govern reads. Retained construction permissions are historical data,
  including when expired or revoked, and cannot authorize another read.
- Yes: authority and a shared cooperative deadline are rechecked around every
  resolver file read and recursive snapshot. A comparison has a 30-second
  cooperative budget, at most 16 lineage layers and a 1 MiB aggregate record;
  unsupported image/PDF renderers, anchors and oversize returns fail closed,
  without truncation. This is not a preemptive parser or filesystem timer.
- Yes: a new layer requires its own source-visible assessment and exact
  comparison evidence. A predecessor's admission is not transferred. Purpose,
  risk, competence, independent execution and policy remain with the unchanged
  journal/assessment engine. Dependent decisions retain the existing exact
  quality-basis withdrawal and reassessment rules.
- Yes: all comparison content remains private and publication unauthorized.
  Supplied producer metadata remains unverified; comparison neither executes
  nor attests OCR, model invocation or transcription. No source records,
  historical reviews, accepted uses, public graph or canon are rewritten.

The checklist's counterpart, lived-witness, golden-kernel, canon-mirror and
durable-decision transitions are not applicable. This source review does not
assess any real text, grant linguistic competence or admit a corpus layer.

## Validation status

The initial focused derived-comparison selection passed six tests and five
subtests. Subsequent current-grant/time guards and the expanded lineage/quality
tests are not covered by that result. The first full three-module run was
deliberately interrupted after 411.63 seconds to inspect its two failures;
36 tests and 31 subtests had passed, not the complete suite. Both failures were
test expectations of a top-level `PermissionError`: the new earlier check
correctly denied access inside the unchanged redacting transport, which wraps
it as `NativeTextBindingError`. The tests now require an actual permission
denial in the exception cause chain as well as the unchanged no-content-read
guards; an unrelated binding error cannot satisfy them. No production error
boundary or permission check was weakened. The separate complete module reruns
now pass: comparison 33 tests and 21 subtests (69.02 s), construction 31 tests
and 23 subtests (94.07 s), and quality journal 21 tests and 19 subtests
(657.72 s). This is 85 tests and 63 subtests, with no failure waived. Earlier
attempts were refused by the host memory reserve gate;
no resource check was bypassed and no existing process was changed.

Script/test topology, source-home validation and documentation-currentness
rebuild/check passed together through an admitted 512 MiB owner resource route
(358.5 MiB measured peak, no swap). Documentation currentness is regenerated
after this review. The three module runs peaked at 107.3, 113.0 and 181.5 MiB
respectively; the journal run used 3.2 MiB swap. Test-fixture cost is not a
production runtime benchmark.

A real owner-private English paragraph was transformed through the native NFC
command into a new, independently identified layer. The previous layer and
source were not overwritten. Exact replay returned the same command receipt;
the new layer starts unreviewed and does not inherit citation admission.
The declared Unicode normalization ran and happened to preserve this paragraph's
bytes; this is not evidence of correction or improved quality. A fresh scoped
read produced the complete source/lineage comparison and found it mechanically
eligible for judgment, not approved. The source-visible linguistic assessment
and any new scoped admission remain separate work. No restricted text or
private operator/execution record is included in this public review.
