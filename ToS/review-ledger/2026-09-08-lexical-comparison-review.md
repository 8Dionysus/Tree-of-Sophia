## Owned distinctions and executable route

The [comparison contract](../contracts/lexical-comparison-claim.schema.json)
and [registry explanation](../doctrine/semantic-interchange/README.md#lexical-history-and-translation-comparison)
extend the existing lexical subjects and shared command/reader machinery.
Relation registry 24 declares six distinct predicates: inheritance, borrowing,
lexical formation, cognacy, historical development of a sense and bounded
translation correspondence. Entity registry 25 exposes their nine comparison
properties through existing Claim-property discovery and queries.

Each comparison has concrete Lexeme or Sense endpoints, qualified wording,
source and target usage scopes and separately declared endpoint languages.
Historical comparisons require chronology grounds; cognacy requires common-
origin grounds; translation requires its task scope, preserved aspects and
limitations. Unknown language remains explicit. Description language is not
the language of the described use. Nonempty fields and valid tags do not prove
linguistic correctness or competence.

There is no transitive closure, automatic identity, one-predecessor
cardinality, global etymological tree or invented morphological inventory.
Cognacy has a symmetric reading without generating another Claim. Correcting
a historical account changes the Claim record, not the time or identity of
the language change. A missing translation pair does not prove universal
untranslatability. No new production Python branch or per-type UI screen was
needed for these declared profiles.

The synthetic checks exercise all six predicates through source validation,
both normalized carriers, qualified forms, property queries and reverse focus.
They cover missing specific grounds, invalid endpoint kinds, incompatible
schema drift, unknown JSON retention, negative/unknown polarity, separate
competing Claims and the distinction between history and record correction.
Creation, form writing, correction, old-version inspection and exact replay
use separately delegated existing source-owner operations. They grant no
assessment, admission or publication authority.
