Reviewed: 2026-09-09. This is a public-safe technical account of an actual
confidential source-owner run, not publication of its text, exact private

## What was actually performed

A freshly delegated non-maker agent read one retained English source paragraph,
its neighboring source context, the original acquired representation, its
extraction policy and current rights. It separately assessed:

- the exact TextLayer for `text-layer:citation`;
- one exact complete source-markup TextUnit for `research`, after a current
  layer-quality basis existed.

These are real source-visible decisions through the protected v5 command, not
synthetic fixture labels. The original File, layer, unit, proposed segmentation
and historical embedded review fields were not rewritten. Current scoped use
comes from separate qualified assessment events. Local research access does
not confer publication, translation fidelity, semantic interpretation or canon.

The retained private evidence is held by the Foundation completion owner under
the task's confidentiality boundary. It includes fixed calibration inputs and
key, actual outputs, independently checked execution metadata, issuer audits,
exact requests, immutable journal receipts and before/after current-state
captures. This derivative deliberately omits the private return locators. It
cannot independently reproduce confidential source judgment from public bytes.

## Competence, authority and observed quality

The assessor's actual native execution metadata was independently checked as
`gpt-6-astra` with `high` effort before the admitted continuations. This was not
accepted merely from the assessment's model-name field. Hidden sampling,
weights and a complete hidden-instruction fingerprint were unavailable; neither
signed provider attestation nor bitwise reproducible inference is claimed.

The source/package maker and admitted assessor were separate executing actors.
The issuer independently reviewed the complete outputs against the source.
All model work nevertheless belongs to one correlated model family and all
source representations to one acquired origin, not multiple independent groups.

The twelve-case disclosed-source calibration covered source scope, attribution,
negation, belief versus assertion, representation exactness and a visible
instruction-injection control. Eleven labels matched the fixed key literally.
The remaining answer used an attribution-level rejection instead of the key's
non-establishment label; full rationale review found the intended distinction
preserved without asserting the converse universal proposition. The key was
not changed to produce a perfect score. No substantive error was found in
those twelve explanations, but the set overlaps the actual targets and is not
a held-out or language-wide accuracy estimate.

The actual production work exposed a separate error: the first layer proposal
made an incorrect incidental language identification outside its qualified
scope. Full issuer audit caught it before append. The original proposal was
retained unchanged; the same assessor reconsidered the full output and issued
a corrected proposal. No erroneous proposal was committed and no prior event
was fictitiously superseded. This was one agent correction intervention, not
an error-free autonomous-output result.

Across five substantive output proposals, four favorable decisions were
committed after complete source-visible audit: initial layer and unit decisions,
then their separate renewals. One earlier proposal needed that correction.
The administrative withdrawal below was a fifth committed event, not an adverse
textual finding. No additional material error was found in the corrected and
renewed outputs within this bounded audit. These counts are not an error-rate
estimate for other texts, languages or tasks.

No new human approval was required for any of the four committed substantive
decisions or the administrative withdrawal. The operator's prior direction and
rights restrictions remained governing inputs; this does not establish that
all future decisions or publication can omit their actual human owners. The
run required complete agent issuer audit, not an unobserved zero-cost review.

## Actual withdrawal, replay and recovery

| Observed phase | Layer citation | Dependent unit research | Retained journal batches, layer / unit |
| --- | --- | --- | --- |
| Initial separate admissions | usable with limits | usable with limits | 1 / 1 |
| Own administrative withdrawal | unusable | unusable; old basis stale | 2 / 1 |
| Fresh source-visible layer assessment | usable with limits | still unusable; old basis stale | 3 / 1 |
| Fresh source-visible unit assessment on the new basis | usable with limits | usable with limits | 3 / 2 |

The temporary withdrawal was explicitly requested to exercise the lifecycle.
It did not pretend that the source had become defective, false or unavailable.
It superseded only the assessor's own exact layer decision; the dependent unit's
history remained present. The captures checked matching source snapshots,
current admissions and journal heads before and after each read. They are
consistent bounded reads, not a cross-subject write transaction.

Replaying the old positive layer command returned its original receipt with
current use still false. The old unit command first failed with `JournalConflict`
because its expected quality snapshot was stale. Updating only that snapshot
returned its original unit receipt with current use still false. Neither retry
created another event or revived permission.

The renewed layer judgment produced a new exact quality basis. It did not
make the unit's old judgment current. Only a separate source-visible unit
renewal, explicitly citing the new basis and superseding the old own unit
assessment, restored unit use. A repeat of that renewal returned the same
second unit receipt and current usable-with-limits state. The old unit event
remained inspectable as stale evidence rather than being deleted.

These states were observed while the exact grants were current. Future grant
expiry, revocation, changed source, rights, comparison or quality evidence still
requires current policy evaluation; this report is not a perpetual permission.
