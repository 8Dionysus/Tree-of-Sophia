# Capacity fixture generator responsibility

This source assessment introduces `tos.agent.tos-capacity-fixture-generator`
as a provisional software responsibility bearer for the synthetic capacity
workload. The Agent identity names the maintained generator operation, not a
historical author, a human operator or a legal rights holder.

The existing Agent type permits a persistent person-like responsibility
bearer. Within this explicitly synthetic scope, the software operation bears
the mechanically observable responsibility for composing a new fixture Work.
This is a qualified source assessment by the implementing agent; it does not
extend the Agent schema or establish software personhood outside this scope.

A generated `authored_by` Claim must retain the actual Work identity, this
declared Agent identity, the selected profile and template provenance, and
its synthetic qualification. Copying an upstream author's attribution into
a newly generated Work is unsupported. Upstream source authors retain their
original attribution and evidence.

The record is authored source metadata, not a native creation receipt.
Actual production, schema and semantic validation, source preservation,
review, rights, canon and publication require their own evidence. The
generator's observed execution and exact source/profile digest remain bound
by the workload producer and admission owners; this note supplies no runtime
or admission result.
