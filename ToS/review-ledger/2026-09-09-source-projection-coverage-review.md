# Source-first public catalog coverage

## Scope and observation

This is a mechanical field-retention observation of the current public
source-witness catalog against the ordinary normalized reader, not an assessment
of language, historical truth, source completeness, access permission or canon.
It continues Foundation M01 without calling the public catalog the entire ToS
corpus. The source owner remains `ToS/source-witnesses/`.

The explicit offline command is:

```bash
python scripts/source_witness_projection_coverage.py --rows
```

It enumerates every declared record catalog and every Claim catalog entry,
including families excluded by individual consumer loaders. Each emitted row
returns identity, source path and line, canonical record digest, source-file
hash, field differences, every matching node/relation carrier and next owner.
It does not print source wording or inspect payloads/private native packets.
Absent, null, unknown extensions and boolean versus numeric values remain
distinct. One exact carrier cannot conceal a conflicting second carrier.

The [dated observation](2026-09-09-source-projection-coverage-observation.json)
binds the source commit, diagnostic implementation hash, source revision,
catalog digest and 390 source-file hashes through their aggregate digest.
It retains the complete family summary and all six unresolved rows. The full
665-row listing is reproducible through the command at that source snapshot;
it is not copied into a second inventory.

## Completeness and failure boundaries

The first diagnostic iterations reused selected bibliographic object/Claim
loaders. The source-count guard refused terminal summaries at 655/665 and
660/665 rather than reporting the selected remainder as complete. The final
enumerator reads all source catalogs independently of consumer selection and
reaches 665/665. This observation did not change corpus membership or source
records to make counts agree.

The command checks catalog parity before enumeration and rechecks catalog
membership, source bytes and read-model revision before its terminal summary.
A stream without that summary is incomplete. These boundary checks do not
claim filesystem-transaction isolation against arbitrary concurrent editors.
Canonical JSON retention is distinct from retaining original file formatting;
the source-file hash preserves the latter binding.
