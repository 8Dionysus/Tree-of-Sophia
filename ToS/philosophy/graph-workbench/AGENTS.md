# AGENTS.md

This card applies to `ToS/philosophy/graph-workbench/`.

## Role

This branch owns source-side graph preparation before canon. Its contracts
return through `ToS/philosophy/philosophy.manifest.json` to branch review.

## Branch Routes

| Branch | Owns |
| --- | --- |
| `views/` | source-owned graph lenses and switching contracts |
| `clusters/` | collapse and overview contracts |
| `review-packets/` | review packet shape for agents and operator review |
| `proposed-nodes/`, `proposed-relations/` | pre-canon node and relation pressure |
| `language-packets/` | pre-canon original/ru/en text-bearing packets |
| `branch-fragments/` | local graph fragments before promotion |
| `promotion-ledger/` | route toward canon relation packs |
| `PLANTING_INTERFACE.md` | prepared atlas/dossier material entering review |

## Boundary Routes

Keep lens, cluster and review meaning here. ToS standalone filtering, runtime rendering
and MCP delivery route to `access/`; consumer-specific Neo4j, UI state and
service orchestration remain with the consuming owner. Generated caches do not
become canon. Emit unresolved diagnostics when source data cannot support a
cluster; do not invent facts to complete it.

## Validation

Select `philosophy_topology`, `generated_parity` or the relevant graph route in
[ToS/VALIDATION.md](../../VALIDATION.md). The lane and selected product contract
own generation and validation procedure.
