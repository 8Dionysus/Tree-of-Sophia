## Limits

- This is not a Sefaria copy and does not establish equivalence with its versions.
- Morphology and lemma annotation remain a modern OSHB layer; ancient attribution is unresolved separately.
- Alternative WLC/OSHB edition for the named work need; not a copy of Sefaria or an equivalence claim.
- Original XML bytes and Hebrew character order must be preserved; no NFC normalization.
- Morphological analysis and lemma assignments are modern annotations, not accepted ToS analysis.
- Local file custody and branch route do not admit text, translation, semantics or canon.
