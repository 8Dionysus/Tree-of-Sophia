# Lived Witness

This branch is the private-by-default route for the human root of the
Zarathustra golden kernel.

It can hold a first-person account of reading, rereading, listening to,
reciting, memorizing, and living with *Thus Spoke Zarathustra*. It does not
turn that account into source text, philological evidence, a universal
interpretation, or canon.

## Map

| Path | Use For |
| --- | --- |
| `CAPTURE_PROTOCOL.md` | invocation, capture sequence, authorship, privacy, revision, and promotion boundaries |
| `CAPTURE_FORM.md` | the short human-facing form used one section at a time rather than as a clerical checklist |
| `local-content/` | ignored private packets and raw capture artifacts |
| `ToS/contracts/lived-witness-packet.schema.json` | machine-checkable packet shape |
| `scripts/validate_lived_witness_route.py` | structural and privacy-boundary check only |

## Invocation

The route stays dormant until the author says, in substance:

> I am ready to record a lived witness.

The assisting agent then opens only the next useful prompt from
`CAPTURE_FORM.md`, records the answer without silent rewriting, and returns the
exact body for confirmation. It must not present the whole schema as manual
data entry.

## Authority

An author-confirmed packet is authoritative for **what the author chooses to
say about their own experience at that time**. It is not authoritative for
what Nietzsche wrote, what a German word means, which translation is correct,
what an event objectively was, or what ToS must canonize.

No record is created by this route merely because the route exists.
