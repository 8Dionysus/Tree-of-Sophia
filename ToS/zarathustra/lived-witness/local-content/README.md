# Local lived-witness content

This directory is the private-by-default storage surface for authored
lived-witness packets and raw capture artifacts.

Everything below this README is ignored by Git. Use one directory per packet
identity, preserve fixity and version lineage, and keep files mode `0600`.
Do not place a tracked or public derivative here; create it only through a
separate explicit permission and review route.

No testimony has been created merely by adding this storage boundary.
