# Zarathustra Route

`ToS/zarathustra/` is the first golden growth kernel for Tree of Sophia.

It keeps the first bounded *Thus Spoke Zarathustra* entry legible without
turning the route capsule into source witness, canon, generated export, or
mechanics.

The branch is meant to make the full method of growth learnable. It transfers
source, evidence, interpretation, review, and uncertainty discipline to wider
philosophy; it does not transfer Nietzsche's ontology as a universal schema.

`source-witnesses/ -> zarathustra/ -> canon/ -> public-compatibility/ -> derived-exports/`

The authored source node stays in `ToS/canon/`.
