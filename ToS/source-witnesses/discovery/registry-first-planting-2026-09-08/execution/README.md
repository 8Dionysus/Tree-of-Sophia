# Bounded cross-branch-source-anchors execution record

These scripts retain the explicit 2026-09-08 batch operations. They take their
repository root from this exact evidence location. The frozen manifest and
branch preparations own selection; the scripts cannot select another corpus.
They are subordinate to the reusable `scripts/acquire_registry_sources.py`,
owner schemas, inventories and validators.

After the preparation checkpoint, run acquisition for `--target proverbs`,
then `plant_cross_branch_source_anchors.py proverbs`, close its local boundary and validate the
source foundation before continuing the remaining manifest targets. Following
full acquisition, run planting, local boundaries and the batch report. The
latter produces a reviewed execution-state input; the readiness queue builder
independently checks its exact references and file digests.

`close_local_boundaries.py` only records future server use as not evaluated
and unapproved. It never transfers a file. No script establishes philological,
semantic, translation or canon acceptance. Re-running scripts does not grant
permission beyond the frozen reviewed acquisition operation.
