# EEBO-TCP acquisition: Seneca, Moral Letters, translated by Thomas Lodge

- Source: https://github.com/textcreationpartnership/A11899/blob/7dff018c7bab3a006842e4522455d0181ff58c09/A11899.xml
- Exact source digest and per-letter headings and page locators: source metadata snapshot.
- All 124 numbered letters appear in the keyboarded transcription, including Lipsius’s prefatory arguments and six marginal notes. The TCP identifies 1,450 gap markers across these letters and their arguments: illegible and omitted foreign text are explicitly marked; ten duplicate-page markers do not represent a loss of transcribed text. The source labels the 69th letter LXXIX; its position and opening match letter 69, while the later 79th letter is distinct. Navigation uses 69 and retains the source heading in the source metadata. End-of-line hyphen markers are joined and the four abbreviation marks for -que are rendered {que}; spacing is normalized. Source spelling and uncertainties remain; no scan collation or critical text review is claimed.

- The exact TCP source and extraction script are separate retained files; capture and letter extraction are separate events. Re-executing the retained script reproduced the reading JSON byte for byte.
