# Access profiles

The [standalone profile](standalone.v1.json) selects product components and runtime posture. The [deployment profile](deployment-profile.default.v1.json) records resource values under the [versioned contract](../contracts/deployment-profile.v1.schema.json). Each field description specifies its unit. Missing fields inherit the built-in profile. A null value requires an explicit value at the operation that needs it.

Select a deployment profile with `--profile PATH` or `TOS_DEPLOYMENT_PROFILE`; the flag takes precedence. The executable uses the embedded default when neither is set. The installer reads the four `archive_install` fields, and its four `--max-*` flags override the selected values. The built-in limits use four times the measured software archive values, rounded up to powers of two; the contract records the measurement. Select limits appropriate to the admitted archive. Build, verify, and extract retain their explicit limits. The remaining profile fields describe current defaults and will be connected to their boundaries in later packages.
