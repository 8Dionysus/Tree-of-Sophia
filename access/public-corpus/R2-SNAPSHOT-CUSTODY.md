The [snapshot manifest](snapshots/r2-manifest.v1.json) records every path, digest, size, rights posture and notice key. Distributions include the notice referenced by each object. Both Unicode tables also carry the repository Apache-2.0 notice; distribute both notices with these tables.

The repository license is [Apache-2.0](../../LICENSE). The [Unicode License V3](../shared/UNICODE-LICENSE.txt) permits redistribution when its copyright and permission notice accompanies copies or associated documentation. Its name-use provision also applies. The Rust table identifies the TypeScript table as its input; the [generator](../../rust/crates/tos-ops-mechanics-plan/src/unicode_tables_main.rs) pins four Unicode 16.0.0 UCD inputs. Both tables are `authorized_with_conditions`.

The other 13 files are project-generated repository material and are `authorized` under Apache-2.0. The inventory source is the Git commit above: eleven retired governance files remain available in that history, while the other four snapshot paths remain in the current checkout. The custody manifest refers to the exact historical bytes, rather than a regenerated version.
