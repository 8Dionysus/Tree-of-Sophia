# Retained synthetic Sign source seed

This bounded fixture preserves the source records, native text carriers and
assessment journal produced by the historical synthetic Sign factory. It
contains no actual source assessment or operator grant. `provenance.json`
records the observed capture and each retained file digest.

Only the two protected owner configurations normalize transport paths and uid.
The Rust test relocates those fields, derives the current promotion basis, and
prepares, publishes and replays through the native owner. Historical prepared
outputs and ready reports are not passed into the native command.
